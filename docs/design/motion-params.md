# SPICA 四状态动效参数表

> 配合 `effect-layer-spec.md`（硬约束）使用。所有数值为实现基准；
> 亮/暗主题共用，仅色值不同。

## 0. 全局

| 参数 | 值 |
|---|---|
| 缓动曲线（唯一） | `cubic-bezier(0.4, 0.0, 0.2, 1)`（先慢后慢） |
| 进入过渡 | 淡入 + 上浮 8px，800ms |
| 退出过渡 | 淡出 + 下沉 8px，600ms |
| 状态切换 | 旧元素 600ms 淡出 → 新元素 800ms 淡入（网格原位） |
| 静息呼吸 | 亮度 ±2%，周期 8s，正弦 |
| 网格 | 8pt（CSS 8px 基准；3D 中 1 单位 = 32px 网格） |
| 主体占比 | ≤40% 视口宽 |

## 2. 四状态视觉（遮字可辨）

### 唤醒 wake（瞬时 ~1.2s）
- 角落（左下 24px）圆点 `d=6px`：灰（--ink-dim 40%）→ 砂岩粉，1200ms
- 一次呼吸：opacity 0.6→1→0.85，scale 1.0→1.2→1.0
- TTS 短句回复；**不显示任何文字**

### 聆听 listen（持续）
- 底部声纹线：`height 2px`，距底 96px，宽度 = 视口 40%（左对齐）
- 起伏：幅度 2–10px（随 RMS 0–0.05 映射），颜色雾青，平滑系数 0.25
- 改写进度线：声纹线上方 8px，`height 1px`，灰紫，长度 0→40% 缓推（草稿就绪即满）

### 执行 exec（持续）
- 任务几何体（Box 1.2 单位）悬浮，每 4s 上下 ±0.05 单位（8s 正弦）
- 子步骤几何体（Box 0.4）在任务上方 0.8 单位处依次淡入（800ms），完成的缓慢上升 0.3 并转雾青（1200ms）
- 播报光晕：任务体边缘 `emissiveIntensity` 0.05→0.15 随 RMS（平滑 0.2）
- 唯一强调色仅给当前活动步骤的轮廓线（1px，砖红）

### 完成 done（一次性）
- 任务几何体上升 0.5 单位（1200ms）+ 颜色过渡到雾青（1200ms）
- 一侧小圆点 `d=4px` 2s 内亮起（灰→砂岩粉）
- 一次极轻呼吸（亮度 +3% → 基线，2s）
- 8s 后无新输入 → 全部元素按退出过渡离场

## 3. 错误/确认

- 错误：强调色轮廓 1 次缓慢明暗脉冲（0.15→0.5→0.15，1.6s），不震动
- 确认（结束词二次确认）：任务体暂停呼吸 + 角点圆点转为芥末黄常亮

## 4. 3D 场景

| 参数 | 值 |
|---|---|
| 相机 | OrthographicCamera，等距（旋转 45°/俯角 35.264°）或固定正面低角度 |
| 轨道 | 可选极缓：90s/圈（演示模式默认开，日常关） |
| 光照 | DirectionalLight(1.0, 位置 (3,5,2)) + AmbientLight(0.35) |
| 阴影 | PCFSoftShadowMap，不透明度 0.12，平面 y=-1.2 |
| 雾 | FogExp2 密度 0.02，同底色 |
| 材质 | MeshLambertMaterial（哑光平涂） |
| 几何 | Box/Cylinder/Sphere 组合，禁止外部模型 |
| 降级顺序 | 光晕 → 阴影 → 雾（手势/声纹平滑不降） |

## 5. 音效

| 事件 | 音 | 参数 |
|---|---|---|
| 确认 | 轻木质敲击（正弦 640Hz→520Hz，80ms，-18dB） | 一次 |
| 环境底噪 | 棕噪声 -42dB 常开 | TTS 播报时压至 -50dB（600ms 缓变） |
| 其余 | 无 | 禁止连击/上升音/玻璃声 |

- 相机轨道开
